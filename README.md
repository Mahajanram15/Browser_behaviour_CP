# Browser-to-Backend Behavioral Integrity Verification System

> A research-oriented monorepo for measuring whether browser interaction
> telemetry is consistent with the API activity generated by the same session.

[![Architecture](https://img.shields.io/badge/Architecture-Cross--Layer%20Security-indigo.svg)](docs/architecture.md)
[![API Contract](https://img.shields.io/badge/API-REST%20Contract-cyan.svg)](docs/api-contract.md)
[![Phase](https://img.shields.io/badge/Status-Research%20Foundation-emerald.svg)](README.md)
[![License](https://img.shields.io/badge/License-MIT-blue.svg)](browser-sdk/package.json)

An advanced research-oriented cybersecurity system that correlates client-side
browser motor dynamics with backend API consumption patterns to calculate a
continuous **Behavioral Integrity / Risk Score**. The repository includes the
privacy-preserving browser SDK, FastAPI service, React analyst dashboard,
feature-engineering and ML experiments, PostgreSQL schema, automated tests, and
Docker deployment files.

> **Research status:** This is a prototype and evaluation platform, not a
> drop-in production bot detector. Scores should be validated against the
> target application's traffic and threat model before being used for access
> decisions.

---

## 1. Problem Statement

Conventional anti-bot, anti-scraping, and fraud prevention systems evaluate client signals or backend API metrics in isolation:
- **Client-only defenses** (CAPTCHAs, JS device fingerprinting) can be bypassed by stealth headless browsers replaying mouse trajectories.
- **Backend-only defenses** (WAFs, rate limiters) struggle against low-and-slow attacks utilizing distributed residential proxies.

Automated threat actors routinely decouple the layers — generating fake human UI movements while firing high-frequency, out-of-order, or anomalous API requests directly to backend endpoints.

---

## 2. Research Objective

The objective of this research system is **not** to claim mathematical certainty of human presence. Rather, it computes a quantifiable **Behavioral Integrity / Risk Score** $[0.0, 1.0]$ based on multi-signal cross-layer evidence.

Sessions exhibiting high discordance between browser interaction dynamics and API resource access patterns are identified, challenged, or blocked with full explainability.

---

## 3. Unique Selling Proposition (USP)

> **CROSS-LAYER BEHAVIORAL INTEGRITY**
> 
> Continuous real-time correlation between physical user interface dynamics (mouse curves, typing cadence, scrolling, navigation) and backend API access topology (request order, parameter semantics, frequency).

## 5. Technology Stack

- **Frontend**: React 18, TypeScript, Tailwind CSS, Recharts, Lucide Icons.
- **Browser SDK**: TypeScript (zero runtime dependencies, privacy-preserving).
- **Backend**: Python 3.11+, FastAPI, Pydantic v2, SQLAlchemy (asyncpg).
- **Database**: PostgreSQL 15+.
- **Data & ML**: NumPy, Pandas, Scikit-learn, XGBoost, SHAP.
- **API Semantics & Similarity**: FastText, FAISS.
- **Sequence Modeling**: First/second-order Markov Transition Chains (scikit-learn compatible).
- **Deployment**: Docker, Docker Compose, Nginx.

## 8. Local Setup Instructions

### Prerequisites
- Python 3.11+
- Node.js 18+ and npm
- Docker & Docker Compose (optional for containerized run)

### Option A: Running with Docker Compose (Recommended)
```bash
# 1. Copy environment template
# Windows PowerShell
Copy-Item .env.example .env
# Linux/macOS
cp .env.example .env

# 2. Build and start services
docker-compose -f docker/docker-compose.yml up --build
```
- Frontend Dashboard: `http://localhost:3000`
- Backend API Docs: `http://localhost:8000/docs`
- Health Check: `http://localhost:8000/health`

Stop the stack with:

```bash
docker-compose -f docker/docker-compose.yml down
```

---

### Option B: Running Manually

#### 1. Backend Service
```bash
# From workspace root
python -m venv .venv
# Activate venv:
# Windows: .venv\Scripts\activate
# Linux/macOS: source .venv/bin/activate

pip install -r backend/requirements.txt

# Start FastAPI server
python -m uvicorn backend.app.main:app --host 0.0.0.0 --port 8000 --reload
```

#### 2. Frontend Application
```bash
cd frontend
npm install
npm run dev
```

#### 3. Browser SDK (Build)
```bash
cd browser-sdk
npm install
npm run build
```

## 11. Future Machine Learning Pipeline

1. **Browser Telemetry Engine**: XGBoost binary classifier trained on statistical trajectory dynamics (velocity variance, curvature, keystroke dwell times).
2. **API Semantic Embeddings**: FastText subword tokenization mapped into FAISS vector space to detect semantic intent drift.
3. **API Structure Engine**: CountVectorizer tokenization with Agglomerative Hierarchical Clustering.
4. **Sequence Engine**: Discrete Markov Chain transition matrices modeling UI state to API endpoint causal sequences.
5. **Cross-Layer Fusion**: Weighted fusion combining individual anomaly probabilities and the cross-layer discordance metric $\Phi(S_b, S_a)$.

---

## 12. Security & Privacy Principles

- **Zero Keystroke Content Capture**: The system captures only inter-key time intervals and key-hold durations. Character identities, keys pressed, and strings are stripped before telemetry is emitted.
- **Form Value Isolation**: Form inputs, text areas, search queries, and passwords are never collected.
- **Anonymized Client ID**: Client IP addresses are stored exclusively as SHA-256 salted hashes.
- **Auditable Decisions**: Every elevated risk determination ($R \ge 0.35$) generates SHAP feature attribution rankings and deterministic rule identifiers.
